# АУРА — Умный Дом (Google Home + Tuya) для GitHub Actions

1. Загрузите все файлы из этого архива (включая скрытую папку `.github`) в новый репозиторий на GitHub.
2. Подождите 2 минуты, пока во вкладке **Actions** появится зеленая галочка.
3. Откройте раздел **Releases** на главной странице репозитория и скачайте готовый **`app-debug.apk`** прямо на телефон.
